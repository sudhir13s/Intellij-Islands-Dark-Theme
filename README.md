# IntelliJ Dark Theme for Antigravity & VS Code

A custom, faithful dark theme porting the exact JetBrains color schemes from **PyCharm**, **IntelliJ IDEA**, and **WebStorm**.

## Features

- **Python (PyCharm)**:
  - Inbuilt types (str, list, dict, int, etc.) in PyCharm Blue (#56a8f5)
  - Literals (None, True, False) in Keyword Orange (#cf8e6d)
  - Classes (BaseModel, SiteKind) in IntelliJ Gold (#dfac53)
  - Fields & attributes (self.field, field: type) in IntelliJ Purple (#c77dbb)
  - self & cls in Keyword Orange (#cf8e6d)
  - Functions & methods in Bright Blue (#56a8f5 / #57aaf7)
  - Decorators (@classmethod, @validator) in Olive/Khaki (#b3ae60)

- **Java (IntelliJ IDEA)**:
  - Primitive types (int, boolean, void) in Keyword Orange (#cf8e6d)
  - Classes in IntelliJ Gold (#dfac53)
  - Interfaces in IntelliJ Teal (#16baac)
  - Fields & Member variables in IntelliJ Purple (#c77dbb)
  - Annotations in Olive/Khaki (#b3ae60)

- **React & TypeScript (WebStorm)**:
  - Interfaces & Type Aliases in Teal (#16baac)
  - Classes in Gold (#dfac53)
  - Component properties & Object fields in Purple (#c77dbb)
  - JSX Component Tags in Teal (#2fbaa3)

## Installation

### From VSIX (Offline / Local)
1. In Antigravity or VS Code, press Cmd + Shift + X (Extensions).
2. Click the ... menu (top right of Extensions panel) - Install from VSIX...
3. Select intellij-dark-theme-1.0.0.vsix.
